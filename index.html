Homepage ALTA MALE LAB — rendu attendu et méthode Divi.

Cette page montre les 10 sections de la homepage telles qu'elles doivent apparaître sur le site, en desktop et en mobile. Chaque aperçu est produit par le fichier exact à intégrer : ce que tu vois ici, c'est ce que le fichier donne une fois collé.

Elle remplace le prototype Claude Design (qui demandait un compte) et la page « Design System » de mai. Les fichiers sont les mêmes que dans le K-Drive, dossier 02_HOMEPAGE_CODE (README v1.1).

01 — La règle

Un fichier = un module Code.

Chaque section de la homepage = un seul module Code Divi, dans lequel on colle le fichier HTML/CSS correspondant, tel quel.

Aucun module Texte, Titre, Bouton, Blog, Image ou Séparateur. Aucun réglage de style Divi (police, taille, couleur, espacement, responsive). Aucun texte retapé.

Tout le design (textes, césures, graisses, couleurs, espacements, version mobile) est déjà dans le fichier. Divi sert uniquement de structure : une section, une ligne, une colonne, un module Code.

Les seules modifications permises dans le code sont prévues et signalées : l'adresse des photos (S05 et S08) et, plus tard, les vrais liens et le formulaire.

02 — Réglages Divi

Préparer chaque section.

SectionCouleur de fond #000000. Marges intérieures haut et bas : 0px (chaque fichier gère ses 120 px lui-même).
Ligne (Row)Largeur 100%, largeur max 100%, marges intérieures 0px, gouttière 1. Le fichier centre lui-même son contenu sur 760 px.
ColonneUne seule colonne, marges intérieures 0px.
ModuleUn seul module Code, marges 0px. Coller le fichier complet, de <!-- jusqu'à la dernière balise.
Hero (S01)Même chose, plus : photo B&W en Background Image de la section (Center Right, Cover). Le bloc fait lui-même 100 % de la hauteur de l'écran.

Coller sans abîmer le code

  1. Prendre le fichier depuis cette page (bouton « Copier le code » ou « Télécharger le fichier ») ou depuis le K-Drive, ouvert dans un éditeur de texte (VS Code). Jamais depuis un email ou un document Word : les guillemets seraient modifiés.
  2. Coller dans l'onglet de contenu du module Code, sans rien ajouter ni retirer.
  3. Garder les liens provisoires #journal, #framework, #manifesto, #academy, #quiz tels quels. Ils seront remplacés quand les pages existeront.
  4. Enregistrer, puis vider les caches : Delete Cache (barre WordPress, WP Super Cache), cache CSS de Divi, et Cloudflare si besoin.
  5. Comparer la section avec son aperçu ci-dessous, en desktop puis en mobile.

Si quelque chose ne s'affiche pas comme ici

Ne pas corriger dans Divi et ne pas modifier le code. Envoyer une capture et une phrase qui décrit ce qui se passe (section, desktop ou mobile). Un fichier corrigé, adapté à Divi, est renvoyé.

Les valeurs utilisées dans les fichiers.

Texte
Lato Regular 400 · Light 300 · Bold 700, 18 px minimum
Labels
Poppins 500 · majuscules espacées

Contenu centré sur 760 px maximum · 120 px en haut et en bas de chaque section · aucune ombre, animation ou effet décoratif.
Termes fixes

Polices
Chaque fichier charge Poppins et Lato. Si elles sont déjà chargées dans le thème, la ligne @import peut être retirée de chaque fichier (voir README).
